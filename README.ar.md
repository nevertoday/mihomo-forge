# Mihomo Forge

[简体中文](README.md) · [繁體中文](README.zh-TW.md) · [English](README.en.md) · [日本語](README.ja.md) · **العربية**

**منصة لإعداد Mihomo / OpenClash تعمل داخل المتصفح وتضع الخصوصية أولًا.**
تحوّل عدة لقطات YAML من اشتراكات قصيرة الصلاحية إلى أصول عُقد يمكن إدارتها على المدى الطويل، وتولّد ملف `config.yaml` كاملًا جاهزًا للاستيراد وفق ثلاثة محاور: المنطقة، والمزوّد، وقواعد الخدمات.

🔒 تُحلَّل إعدادات العُقد وتُولَّد داخل هذا المتصفح فقط، ولا يُرفع أي شيء إلى الخادم. لا خادم خلفي، ولا تحليلات، ولا حاجة إلى حساب.

**الاستخدام عبر الإنترنت: <https://nevertoday.github.io/mihomo-forge/>** (صفحة ثابتة، ولا تغادر عُقدك متصفحك)

---

## لماذا

صار كثير من المزوّدين يمنحون **روابط اشتراك قصيرة الصلاحية**: يحمل الرابط رمزًا مؤقتًا ويجب إعادة إنشائه بعد مدة. لذلك تتعطل باستمرار الأدوات التي تفترض رابطًا دائمًا مثل Sub-Store و`proxy-provider`.

الأصل الذي يدوم فعلًا هو **لقطة YAML التي نزّلتها أثناء صلاحية الرابط**.

<div dir="ltr">

```text
provider-a.yaml  provider-b.yaml  provider-c.yaml  …
        ↓  drop into Mihomo Forge
sources → regions → node strategies → service strategies → rules
        ↓
     config.yaml → OpenClash / Mihomo
```

</div>

العمل اليومي خطوة واحدة: نزّل ملف YAML الجديد، وأفلِته في الصفحة، وأكّد الاستبدال، ثم أعد التوليد. تبقى القواعد والمناطق واستراتيجيات الخدمات كما هي.

## الميزات

- **استيراد ملفات متعددة**: أفلِت عدة ملفات `.yaml/.yml` معًا، ويصبح اسم كل ملف اسمَ المصدر (المزوّد)
- **قراءة `proxies` فقط**: تُتجاهل `proxy-groups` و`rules` و`dns` و`rule-providers` الخاصة بالمزوّد
- **بادئة المصدر**: تُسمّى العُقد بصيغة `[المصدر] الاسم الأصلي`، وتُرقَّم الأسماء المكررة `#2` و`#3`
- **إزالة التكرار بالبصمة**: بصمة SHA-256 من type / server / port / uuid / password وخيارات النقل؛ شاملة أو داخل كل مصدر أو معطّلة
- **التعرف على المنطقة**: جدول تعابير نمطية قابل للتعديل (20 منطقة)، مع إمكانية تحديد منطقة كل عقدة يدويًا
- **طريقتان متوازيتان لاختيار العُقد**
  - عام: `🌍 الكل · يدوي` · `⚡ الكل · تلقائي` · `🛡 تجاوز الأعطال`
  - حسب المنطقة: `🇺🇸 الولايات المتحدة · تلقائي` … (لا مجموعات فارغة)
  - حسب المزوّد: `📦 provider-a` · `📦 provider-b` …
  - تركيبات المزوّد × المنطقة: عند الطلب فقط، دون توليد كل التركيبات
  - حسب كلمات اسم العقدة: مثل العُقد التي يحتوي اسمها على «IEPL»، مع إمكانية حصرها في مصادر ومنطقة ومعاينة النتائج قبل الإنشاء
- **استراتيجيات الخدمات**: ChatGPT وClaude وGemini وGitHub وYouTube وNetflix وTelegram… لكل منها مجموعة `select` مستقلة **تستطيع استخدام المناطق والمزوّدين معًا**
- **إعدادات قواعد معيارية**: Lite / Standard / Full / Custom مع وحدات AI وDeveloper وStreaming وSocial وGaming وCrypto وAds
- **ترتيب صارم للقواعد**: الشبكة المحلية ← الإعلانات ← الذكاء الاصطناعي ← التطوير ← البث ← التواصل ← خدمات أخرى ← البر الصيني ← الخارج ← MATCH (تأتي Gemini دائمًا قبل Google)
- **التحقق من المراجع**: أسماء مجموعات فريدة، وكل مرجع وRULE-SET موجود، وMATCH في النهاية؛ ويُمنع التصدير عند وجود أخطاء
- **فروقات التحديث**: عند استبدال مصدر تظهر العُقد المضافة والمحذوفة والمعاد تسميتها
- **قوالب أساسية**: OpenClash القياسي / Mihomo العام / ملف `base.yaml` خاص بك
- **المشاريع**: تُحفظ الإعدادات والعُقد في IndexedDB، ويمكن تصدير `mihomo-forge-project.json` (دون بيانات الاعتماد افتراضيًا)
- **تعدد اللغات**: 简体中文 و繁體中文 وEnglish و日本語 والعربية (مع تخطيط من اليمين إلى اليسار). ولأسماء المجموعات في الإعداد المولَّد إعداد لغة مستقل

مجموعات القواعد هي ملفات `.mrs` من [MetaCubeX/meta-rules-dat](https://github.com/MetaCubeX/meta-rules-dat) عبر jsDelivr أو GitHub.

## البدء السريع

<div dir="ltr">

```bash
git clone https://github.com/nevertoday/mihomo-forge.git
cd mihomo-forge
npm install
npm run dev        # http://localhost:5173
```

```bash
npm test           # core compiler + i18n tests (Vitest)
npm run build      # type-check + static build in dist/
```

</div>

المجلد `dist/` ملفات ثابتة فقط، يمكن نشرها على GitHub Pages أو Cloudflare Pages أو أي استضافة ثابتة. يتضمن المستودع سير عمل جاهزًا لـ GitHub Pages في `.github/workflows/pages.yml`.

اختر اللغة من الشريط العلوي، أو افتح الرابط مباشرة مع `?lang=ar`.

## الاستيراد إلى OpenClash

1. في OpenClash افتح «إدارة ملفات الإعداد» وارفع ملف `config.yaml` المولَّد ثم فعّله. يلزم **نواة Meta (Mihomo)** لأن مجموعات القواعد بصيغة `.mrs`.
2. عند أول تشغيل تُنزَّل نحو 20–45 مجموعة قواعد عبر مجموعة «🌐 الخارج» افتراضيًا. قد يفشل بعضها قبل اختبار العُقد، فيعيد Mihomo المحاولة تلقائيًا ويكتمل كل شيء عادةً خلال دقيقة، ثم تُحمَّل لاحقًا فورًا من ذاكرة `./ruleset/`.
3. يُتحقق من كل إعداد مولَّد بنواة Mihomo الحقيقية: يُقرأ أولًا ويُعاد كتابته بمكتبة YAML في Ruby (كما يفعل OpenClash) ثم يُشغَّل `mihomo -t`. وتوضع القيم التي يسيء YAML 1.1 فهمها مثل `off` و`yes` و`0755` بين علامات اقتباس دائمًا.

## الخصوصية والأمان

- تُقرأ الملفات عبر File API في المتصفح، ويجري التحليل والتوليد محليًا
- لا واجهات برمجية خارجية ولا تحليلات؛ الطلب الخارجي الوحيد هو خطوط الويب
- تُحفظ بيانات العُقد في IndexedDB فقط، ولا تُكتب في localStorage أبدًا
- لا تتضمن ملفات المشروع المصدَّرة server / uuid / password افتراضيًا

لمسائل الأمان راجع [SECURITY.md](SECURITY.md).
